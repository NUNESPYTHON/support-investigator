# 🔎 Zendesk Investigator

## Missão

Reduzimos o tempo de investigação para que você passe mais tempo resolvendo problemas do que procurando informações.

## Não estamos construindo outro Zendesk.

Estamos construindo uma ferramenta que ajuda engenheiros de suporte a investigar problemas com rapidez, clareza e contexto.

---

## Sobre o projeto

O Zendesk Investigator é uma ferramenta de apoio para equipes de suporte.

Seu objetivo não é substituir o Zendesk.

Seu objetivo é organizar informações importantes de forma rápida, reduzindo o tempo gasto durante uma investigação.

---

## Objetivos

- Consultar clientes
- Consultar tickets
- Investigar tickets
- Exibir métricas importantes
- Facilitar investigações
- Gerar relatórios
- Exportar informações

---

## Filosofia

Cada funcionalidade desenvolvida deve responder a três perguntas:

1. Qual problema ela resolve?
2. Quanto tempo ela economiza?
3. Como ela ajuda o analista?

Se não responder essas perguntas, ela não entra no MVP.
