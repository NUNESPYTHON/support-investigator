Support Investigator
Missão

O Support Investigator não mostra apenas dados.

Ele organiza o contexto necessário para que líderes técnicos, engenheiros de suporte, account managers e gestores compreendam rapidamente a situação de um ticket e tomem decisões com segurança.

O Investigator não replica o Zendesk.

Ele transforma informações técnicas em contexto para acelerar investigações e apoiar a tomada de decisão.

Não estamos construindo outro Zendesk.

Estamos construindo uma ferramenta que ajuda engenheiros de suporte e gestores a investigar problemas com rapidez, clareza e contexto.

Público-alvo

O Support Investigator foi desenvolvido para:

Líderes técnicos
Engenheiros de suporte
Gerentes de suporte
Account Managers
Gestores de atendimento

Seu objetivo é fornecer rapidamente o contexto completo de um ticket, reduzindo a necessidade de navegar por diversas telas dentro do Zendesk.

Sobre o projeto

O Support Investigator é uma ferramenta de apoio para equipes de suporte.

Seu objetivo não é substituir o Zendesk.

Seu objetivo é organizar informações relevantes de forma rápida, reduzindo o tempo gasto durante investigações e facilitando análises técnicas.

Objetivos
Consultar clientes
Consultar tickets
Investigar tickets
Exibir métricas relevantes
Facilitar investigações
Gerar relatórios
Exportar informações
Filosofia

Cada funcionalidade desenvolvida deve responder a três perguntas:

Qual problema ela resolve?
Quanto tempo ela economiza?
Como ela ajuda o analista?

Se não responder essas perguntas, ela não faz parte do MVP.

Princípios
Nunca obrigar o usuário a abrir o Zendesk para responder uma pergunta simples.
Transformar dados técnicos em contexto para tomada de decisão.
Mostrar primeiro as informações mais importantes.
Cada tela deve responder uma necessidade real do usuário.
Priorizar simplicidade, velocidade e clareza.
